01 · Objective

A small pipeline demonstrating a complete data movement cycle.

The project retrieves current conditions for Lagos, Ibadan and Abuja, selects the required variables, structures them with Pandas and writes the result to CSV. It focuses on a repeatable technical workflow rather than claiming that three current observations constitute a substantive weather study.

02 · Extract

Request live data safely.

A loop sends a GET request to the OpenWeather current-weather endpoint for each city. Metric units are specified, unsuccessful HTTP responses trigger an error, and the API key is retrieved from Google Colab Secrets rather than embedded in the public notebook.

03 · Transform

Turn nested JSON into analytical rows.

Each response is reduced to the fields required for analysis: city, temperature, humidity, condition, wind speed and timestamp. Dictionaries are collected into a list and converted into a Pandas DataFrame.

  • Inspected structure and data types.
  • Checked missing values and duplicates.
  • Converted timestamps to Pandas datetime.
  • Created separate date and time fields.
  • Sorted observations by temperature and reset the index.

04 · Load

Persist the result for reuse.

The transformed DataFrame is written to weather_data.csv without an unnecessary index column, then loaded back into Pandas to confirm successful storage.

05 · Reliability choices

Small details that prevent fragile pipelines.

  • raise_for_status() prevents failed requests from silently entering the workflow.
  • Secrets management keeps credentials outside version control.
  • Explicit field selection produces a stable, analysis-focused schema.
  • Missing-value and duplicate checks create a basic data-quality gate.

06 · Next iteration

From demonstration to production-minded pipeline.

A stronger version would schedule repeated collection, add retries and logging, preserve historical observations in a database, validate schemas, handle rate limits and attach automated tests. Those are genuine next steps; the current project should not be presented as a production pipeline.
